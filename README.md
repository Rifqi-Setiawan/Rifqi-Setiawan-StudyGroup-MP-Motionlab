# Week 8 - firebase
Firebase adalah platform pengembangan aplikasi dari google yang menyediakan layanan seperti penyimpanan data, autentikasi, analisis, dan lainnya.

## Firestore
Firestore adalah salah satu layanan cloud database dari firebase. Firestore memungkinkan menyimpan dan mengelola data aplikasi secara mudah.

### Firestore fundamentals
- Collection = sekumpulan document dalam firestore.
- Document = tempat di mana anda menyimpan data didalam firestore dan tiap document memiliki kumpulan data yang berisi informasi
